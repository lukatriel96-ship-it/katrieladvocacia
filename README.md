# Katriel & Freitas Advogados — Landing page BPC/LOAS

Site estático em HTML, CSS e JavaScript, pronto para GitHub e Vercel.

## Publicação no GitHub + Vercel

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Na Vercel, clique em **Add New > Project**.
4. Importe o repositório do GitHub.
5. Em **Framework Preset**, use **Other**.
6. Não é necessário configurar comando de build.
7. Clique em **Deploy**.

## Personalização recomendada antes de publicar

- Substitua a imagem ilustrativa do hero por uma foto real dos advogados do escritório. O arquivo `index.html` contém a URL da imagem atual dentro do bloco `.hero-person`.
- Insira endereço, e-mail e números da OAB caso queira exibi-los no rodapé.
- Se desejar, troque o monograma K&F por um arquivo de logo oficial.
- Revise as informações jurídicas e publicitárias com os responsáveis pelo escritório antes da publicação definitiva.
